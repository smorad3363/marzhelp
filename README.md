# MarzHelp

ربات مدیریت نمایندگان و کاربران Marzban.

## نصب یا به‌روزرسانی

دستور زیر هوشمند است:

- اگر MarzHelp نصب نشده باشد، نصب کامل را اجرا می‌کند.
- اگر نصب قبلی وجود داشته باشد، از برنامه و پایگاه‌داده‌ها نسخهٔ پشتیبان می‌گیرد و سپس آن را به نسخهٔ این مخزن ارتقا می‌دهد.
- فایل `config.php` و اطلاعات ربات حفظ می‌شوند.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/smorad3363/marzhelp/production/bootstrap.sh)
```

نسخهٔ پایدار از شاخهٔ `production` نصب می‌شود.

## به‌روزرسانی مستقیم

برای سروری که از قبل به این مخزن منتقل شده است:

```bash
bash /var/www/html/marzhelp/update.sh
```

نسخه‌های پشتیبان با دسترسی محدود داخل مسیر زیر نگهداری می‌شوند:

```text
/var/backups/marzhelp
```

## نکتهٔ شبکه

در نصب اولیه، درگاه `80` موقتاً برای دریافت گواهی Let's Encrypt استفاده می‌شود. سرویس نهایی روی درگاه `88` در دسترس خواهد بود.
